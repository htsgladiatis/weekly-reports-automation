# Настройка доступа к Яндекс.Директ API

## Проблема
```
error_code: 58
error_string: "Незавершённая регистрация"
```

Для использования API Яндекс.Директа необходимо заполнить заявку на доступ.

---

## Шаг 1: Заполните заявку

1. Перейдите в Яндекс.Директ: https://direct.yandex.ru/
2. Войдите в аккаунт с рекламными кампаниями
3. Перейдите в раздел **API** или настройки приложения

Или откройте: https://oauth.yandex.ru/ (раздел "Мои приложения")

---

## Шаг 2: Заполните информацию о приложении

Если приложение "Dune Dashboard" создано:
1. Выберите приложение
2. Нажмите "Редактировать"
3. В разделе "Доступ к API Яндекс.Директа" заполните:
   - Название приложения: Dune Dashboard
   - Описание: Автоматизация отчётов по рекламе
   - Сайт: https://dune-group.ru
   - Тип приложения: Веб-приложение

---

## Шаг 3: Отправьте заявку на доступ

После заполнения нажмите "Сохранить" и отправьте заявку на рассмотрение.

⚠️ **Важно**: Заявка рассматривается Яндексом. Обычно это занимает 1-3 дня.

---

## Альтернатива: Ручной ввод данных

Пока заявка рассматривается, можно создать отчёт вручную:
1. Скопировать данные из скриншотов Директа
2. Создать report_0106.py с этими данными
