# Настройка вебхука Битрикс24

## Портал: https://dunegroup.bitrix24.ru/

---

## 📋 Пошаговая инструкция

### Шаг 1: Откройте настройки интеграций
1. Зайдите на https://dunegroup.bitrix24.ru/
2. В левом меню найдите **Раздел "Разработчикам"**
3. Или нажмите на иконку шестерёнки (⚙️) в правом верхнем углу → **Другое**

### Шаг 2: Создайте входящий вебхук
1. В разделе "Разработчикам" выберите **Входящий вебхук**
2. Нажмите кнопку **Добавить вебхук**

### Шаг 3: Заполните настройки
1. **Название**: `Weekly Reports Integration`
2. **Описание**: `Для автоматизации еженедельных отчетов по рекламе`
3. **Права доступа**: отметьте галочкой **CRM** (достаточно для чтения лидов)
4. Нажмите **Сохранить**

### Шаг 4: Скопируйте URL вебхука
После сохранения появится окно с URL вида:
```
https://dunegroup.bitrix24.ru/rest/1/XXXXXXXXXXXX/crm.lead.list/
```

**Этот URL — ваш вебхук!** Скопируйте его полностью.

---

### 📌 Альтернативный путь (через админку):

1. https://dunegroup.bitrix24.ru/developer/
2. https://dunegroup.bitrix24.ru/devops/
3. Выберите **Создание вебхуков**
4. Тип: **Входящий**
5. Права: CRM

## Шаг 2: Получите URL вебхука

После сохранения вы получите URL вида:
```
https://dunegroup.bitrix24.ru/rest/1/XXXXXXXXXXXX/
```

**Скопируйте этот URL** — он понадобится для настройки.

## Шаг 3: Настройка в проекте

### Вариант A: Переменная окружения (рекомендуется)
```bash
# Windows
set BITRIX_WEBHOOK_URL=https://dunegroup.bitrix24.ru/rest/1/XXXXXXXXXXXX/

# Или добавьте в системные переменные окружения
```

### Вариант B: Прямо в коде
Откройте `bitrix.py` и измените строку:
```python
WEBHOOK_URL = "https://dunegroup.bitrix24.ru/rest/1/XXXXXXXXXXXX/"
```

## Шаг 4: Тестирование

После настройки запустите:
```bash
python bitrix.py 2026-06-01 2026-06-07
```

Должна вывестись статистика лидов за период.

---

## ⚠️ Важно

- Вебхук создаётся от имени пользователя-администратора
- Права `CRM` позволяют читать лиды и статусы
- URL вебхука начинается с `/rest/1/` — это код авторизации
