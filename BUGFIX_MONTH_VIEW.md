# 🐛 Bugfix: Исправление просмотра по месяцам

## 📋 Проблемы

### 1. Кнопка "Все недели" 
**Проблема:** Отдельная кнопка "Все недели" занимала много места и создавала избыточность.

**Решение:** ✅ Удалена кнопка, опция "Все недели/месяцы" перенесена в выпадающий список как первый пункт.

### 2. Некорректное отображение данных по месяцам
**Проблема:** При выборе конкретного месяца данные в KPI боксах и графиках отображались неправильно.

**Причина:** 
- Функция `aggregateWeeks()` не передавала `id` месяца
- Отсутствовал параметр `monthId` в агрегированных данных
- Это приводило к ошибкам при поиске данных

**Решение:** ✅ Исправлены функции агрегации данных.

## 🔧 Технические изменения

### 1. HTML структура

**Было:**
```html
<button class="period-btn">Все недели</button>
<select class="week-select">
    <option value="">Выберите неделю...</option>
    ...
</select>
```

**Стало:**
```html
<select class="week-select">
    <option value="all">Все недели</option>
    <option value="w1">04.05–10.05</option>
    ...
</select>
```

### 2. JavaScript функции

#### aggregateWeeks()
**Было:**
```javascript
function aggregateWeeks(weekIds, label) {
    // ... агрегация данных
    agg.label = label;
    agg.short = label;
    return agg;
}
```

**Стало:**
```javascript
function aggregateWeeks(weekIds, label, monthId) {
    // ... агрегация данных
    agg.id = monthId;  // ✅ Добавлен ID
    agg.label = label;
    agg.short = label;
    return agg;
}
```

#### getMonthsData()
**Было:**
```javascript
return months.map(m => aggregateWeeks(m.weeks, m.short));
```

**Стало:**
```javascript
return months.map(m => aggregateWeeks(m.weeks, m.short, m.id));
```

#### getDataForPeriod()
**Было:**
```javascript
return [aggregateWeeks(month.weeks, month.label)];
```

**Стало:**
```javascript
return [aggregateWeeks(month.weeks, month.label, month.id)];
```

#### showPeriod()
**Было:**
```javascript
const allBtn = document.querySelector('.period-btn');
if (period === 'all') {
    allBtn.classList.add('active');
    dropdown.value = '';
}
```

**Стало:**
```javascript
const dropdown = document.querySelector('.week-select');
dropdown.value = period;  // Просто устанавливаем значение
```

#### updateMonthSelector()
**Было:**
```javascript
select.innerHTML = '<option value="">Выберите месяц...</option>';
```

**Стало:**
```javascript
select.innerHTML = '<option value="all">Все месяцы</option>';
```
