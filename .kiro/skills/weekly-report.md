## Источники данных

Пользователь присылает данные в 3 блока:
1. **Яндекс Директ** — JSON из 4 кабинетов (показы, клики, расход, конверсии по кампаниям)
2. **CRM** — CSV с лидами (стадия, источник, дата). Целевые = стадия "Целевой лид"
3. **Метрика** — JSON с визитами, источниками трафика (SEO = search_engine_visits)

## Расчёт метрик

- CTR = (Визиты / Показы) × 100%, 2 знака
- CPC = Расход / Визиты, целые рубли
- CPA = Расход / Лиды, целые рубли
- CPL = Расход / Целевые Лиды, целые рубли
- Конверсия в Лид = (Лиды / Визиты) × 100%, 2 знака
- Конверсия в Ц. Лид = (Целевые Лиды / Лиды) × 100%, 2 знака
- При делении на 0 → прочерк `—` или `-`

## Форматирование

- Денежные столбцы: `р.X XXX` (с разделителем тысяч)
- Проценты: `X,XX%`
- Жирный: заголовки, итого, строки аккаунтов, SEO, Рекомендации
- Столбец A: ширина 380px

## Подсчёт лидов

- **Лиды** = все записи из CRM с источником "Яндекс.Директ" или UTM direct, исключая стадии: Дубль, Подрядчики реклама, Ошиблись номером, Вакансии
- **Целевые лиды** = стадия "Целевой лид"
- Распределение по аккаунтам: по UTM `utm_campaign=cabinet-XXXXX` или по умолчанию в e-20010227 (marquiz)

## Процесс

1. Получить данные из 4 кабинетов Директа
2. Получить CRM (целевые лиды)
3. Получить Метрику (визиты SEO)
4. Подсчитать лиды и целевые по аккаунтам
5. Собрать отчёт в структуре таблицы
6. Записать в Google Sheets новой вкладкой (имя = период)
7. Вкладка на позиции 0 (крайняя левая)
