Рекомендации
Настройка рекламных кампаний

Сгруппированы по приоритету. Раскройте блок для деталей.

!Срочно — остановить утечки›
  • Снизить/отключить РСЯ (45 227 ₽, 0 ЦЛ): оставить 1 тест с ручным контролем площадок, бюджет перевести на поиск.
  • Корректировка ставок −80…−100% на смартфоны в поисковых кампаниях (CR 0,3%).
  • Пересмотреть «МК // CPA Цель» (9 337 визитов, 1 ЦЛ): авто/сети дают объём без качества.
  • Загрузить минус-слова: «вакансии», «работа», «найм», «резюме» + города без посадочных. По Директу — пул ~235 тыс. ₽ нецелевых запросов.
▣Аналитика и атрибуция›
  • Передавать оффлайн-конверсии в Директ из Roistat/CRM: целевой лид и сделка. Сейчас автостратегии оптимизируются по заявкам, а не по ЦЛ.
  • Оптимизировать на ЦЛ, а не на заявки: CPL 3 523 ₽ выглядит нормально, но цена ЦЛ 19 068 ₽ — реальный ориентир.
  • Следить за этапом «ЦЛ → Продажа» (сейчас 2,9%): подключить отдел продаж, фиксировать причины отказов.
◆Структура и стратегии›
  • Разделить Поиск и РСЯ в отдельные кампании с раздельными бюджетами.
  • Перенести бюджет на лидеров по ЦЛ: «Склад. Москва» (5 ЦЛ), «Города. СПб» (4 ЦЛ), «Аутсорсинг. Москва» (CPL 2 300 ₽).
  • Автотаргетинг — только на поиске-десктопе, режим «целевые + близкие».
  • Стратегии: пока ЦЛ не передаются — «Макс. кликов с ручными ставками» на поиске; после накопления — переход на оплату за конверсию.
  • Гео-приоритеты: усилить Омск (CPA 793 ₽, CR 39%), СПб (CR 31,9%); по Москве — пересобрать семантику.
↻Контроль и регламент›
  • Еженедельный отчёт по поисковым запросам → пополнение минус-слов.
  • KPI: цена ЦЛ и CPO вместо «голого» CPL.
  • Контроль баланса и темпа: при текущем росте CPA бюджет расходуется быстрее плана.
