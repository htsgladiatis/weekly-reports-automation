## 🎯 Обзор проекта

### Цель
Автоматизация еженедельной отчетности по рекламным кампаниям Яндекс.Директ с интеграцией:
- 4 рекламных кабинетов Яндекс.Директ
- CRM-системы Битрикс24 (лиды и целевые лиды)
- Яндекс.Метрики (визиты, источники трафика)
- Автоматическое создание отчетов в Google Sheets
- Интерактивная веб-версия с графиками и таблицами

### Текущий этап
**Production Ready** — все API подключены, автоматизация работает, отчеты создаются автоматически.

## 📊 Структура отчета

### 4-уровневая иерархия

1. **Итого** — сумма всех каналов
2. **Яндекс Директ** — сумма 4 аккаунтов
3. **Аккаунты** — e-20010227, e-17228851, dune-group, porg-3uieikjn
4. **Кампании** — детализация под каждым аккаунтом
5. **SEO** — отдельная строка (визиты из Метрики)
6. **Рекомендации** — отдельная строка

### 12 колонок метрик

| # | Колонка | Формула | Описание |
|---|---------|---------|----------|
| 1 | Канал | — | Название канала/аккаунта/кампании |
| 2 | Показы | — | Количество показов рекламы |
| 3 | Визиты | — | **КЛИКИ** из Директа (НЕ из Метрики!) |
| 4 | CTR | `(Клики / Показы) × 100%` | Кликабельность, 2 знака после запятой |
| 5 | CPC | `Расход / Клики` | Стоимость клика, целые рубли |
| 6 | Лиды | — | Количество лидов |
| 7 | Конверсия в Лид | `(Лиды / Клики) × 100%` | Конверсия в лид, 2 знака |
| 8 | CPA | `Расход / Лиды` | Стоимость лида, целые рубли |
| 9 | Ц. Лиды | — | Целевые лиды (стадия "S" в Битриксе) |
| 10 | Конверсия в Ц. Лид | `(Целевые / Лиды) × 100%` | Конверсия в целевой лид, 2 знака |
| 11 | CPL | `Расход / Целевые Лиды` | Стоимость целевого лида, целые рубли |
| 12 | Расход | — | Расход в рублях |

**Правило деления на 0:** при делении на 0 выводится прочерк `—` или `-`

**Статус:** Активна  
**Вебхук:** `https://dunegroup.bitrix24.ru/rest/396/vk0fdm6r1qrtt81w/`  
**Тип:** REST API (входящий вебхук)

#### Функционал
- Загрузка лидов за период
- Фильтрация по источникам: `Яндекс.Директ`, `Билайн АТС 9094091176`
- Исключение брака (семантика стадии `F`)
- Подсчет целевых лидов (семантика стадии `S`)
- Атрибуция по UTM или по умолчанию на `e-20010227`

#### Использование
```bash
python bitrix.py 2026-06-01 2026-06-07
```

#### Ключевые настройки
```python
WEBHOOK_URL = "https://dunegroup.bitrix24.ru/rest/396/vk0fdm6r1qrtt81w/"
DIRECT_SOURCE_NAMES = {"Яндекс.Директ", "Билайн АТС 9094091176"}
SEMANTIC_SUCCESS = "S"  # Целевой лид
SEMANTIC_FAILURE = "F"  # Брак (исключается)
DEFAULT_ACCOUNT = "e-20010227"
```

## 🔑 Ключевые правила и логика

### Атрибуция лидов

#### Источники, считающиеся Директовыми:
1. `Яндекс.Директ` (SOURCE_ID из Битрикса)
2. `Билайн АТС 9094091176` (звонки без коллтрекинга)
3. UTM medium = `direct`
4. SOURCE_DESCRIPTION = `marquiz`

#### Исключаемые стадии (брак, семантика `F`):
- Дубль
- Подрядчики реклама
- Ошиблись номером
- Вакансии
- Нецелевой лид
- Не отвечает (Пропал)
- Не проходит по бюджету
- Выбрал другого подрядчика
- и другие со статусом `F`

#### Целевые лиды (семантика `S`):
- **Целевой лид** (CONVERTED в Битриксе)

#### Атрибуция по аккаунтам:
1. Если есть `utm_campaign` с подстрокой из `ACCOUNT_BY_UTM_CAMPAIGN` → соответствующий аккаунт
2. Иначе → `e-20010227` (по умолчанию)

### Важные правила данных

1. **Столбец "Визиты" для Директа = КЛИКИ** (не визиты из Метрики!)
2. **Визиты из Метрики** используются только для строки SEO
3. **Каждая кампания** должна иметь свои реальные показы и клики из скриншотов
4. **При делении на 0** → прочерк `—` или `-`
5. **CTR и конверсии** → 2 знака после запятой (например, `2,97%`)
6. **CPC, CPA, CPL** → целые рубли (например, `р.6 031`)
7. **Расход** → с разделителем тысяч (например, `р.96 494`)

### Формат названий

- **Вкладка Google Sheets:** `DD.MM-DD.MM` (например, `01.06-07.06`)
- **Скрипт отчета:** `report_DDMM.py` (например, `report_0106.py`)
- **Папка с данными:** `D-D.MM/` (например, `1-7.06/`)
- **Excel файлы:** `Новый YYYY-MM-DD_HH-MM-SS_ACCOUNT.xlsx`
