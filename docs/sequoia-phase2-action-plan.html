Почему CTR низкий? Позиции 10–27 — глубоко за 1-й страницей. Title/description не привлекают клик. Нужны УТП + CTA.

Формула нового Title

[Услуга] + [Гео] + [Триггер/Цена] + [Бренд]

Пример: Аутсорсинг грузчиков в Москве от 280 руб/час — Sequoia Service (68 символов)

Пошаговые инструкции: переписать Title и Description

  1. Открыть Tilda → страница (например, /autsorsing-personala-na-proizvodstvo)
  2. Шестерёнка → Настройки страницы → SEO
  3. Поле Title: вставить новый title из таблицы выше (до 60 символов)
  4. Поле Description: вставить новый description (150–160 символов, с CTA)
  5. Сохранить → Опубликовать
  6. Повторить для всех страниц из таблицы ниже
Приоритет: Начните с 5 страниц с самым высоким трафиком из GSC: главная, /autsorsing-personala-na-proizvodstvo, /arenda-personala, /autsorsing-personala-na-sklad, /autsorsing-personala-dlya-ritejla.

Пошаговая инструкция

  1. Tilda → Настройки сайта → Head → вставить Organization или LocalBusiness (на все страницы)
  2. На каждой странице услуг добавить блок T123 (HTML-код) → вставить Service + Offer
  3. Если на странице есть FAQ — добавить FAQPage в тот же T123 блок
  4. Опубликовать каждую страницу
  5. Проверить через Rich Results Test

7. Исправить внутренние ссылки — убрать ссылки на дубли

Результат проверки: ВСЕ ССЫЛКИ ЧИСТЫЕ

Почему всё чисто? Tilda управляет внутренними ссылками автоматически. Когда вы убрали дубли с суффиксом «3» и страницы «_old», Tilda обновила меню и навигацию. Вручную править ссылки не нужно.
Screaming Frog можно запустить для дополнительной проверки, но в Tilda нет доступа к шаблонам для ручного редактирования href. Всё управляется через интерфейс Tilda.

Canonical на 404 странице указывает на page87072856.html — это Tilda-страница 404. Не критично, но идеально бы убрать canonical с 404 или сделать его self-referencing.

Что улучшить в Tilda

  1. Tilda → Настройки сайта → Страница 404 → выбрать страницу или создать новую
  2. Создать страницу /404 с:
    • Логотип + навигация (уже есть)
    • Телефон / кнопка «Позвонить» (уже есть)
    • Поисковая форма (НЕТ — добавить!)
    • Популярные ссылки: услуги, контакты, цены
    • Дружелепное сообщение: «Страница не найдена, но мы готовы помочь»
  3. Убрать canonical с 404-страницы или сделать <link rel="canonical" href="https://sequoia-service.ru/404">
  4. Опубликовать
Мониторинг 404 в GSC: GSC → Pages → Not Indexed → Soft 404 / 404. Экспорт раз в неделю не требует Клода — просто заходите в GSC и смотрите список.
