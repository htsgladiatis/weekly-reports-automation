# Weekly Reports Automation - Яндекс.Директ → Google Sheets

Автоматизация еженедельной отчетности по рекламным кампаниям Яндекс.Директ в Google Sheets.

## 📊 Описание проекта

Проект включает Python-скрипты для генерации структурированных еженедельных отчетов с данными из:
- 4 рекламных кабинетов Яндекс.Директ (e-20010227, e-17228851, dune-group, porg-3uieikjn)
- CRM-системы (лиды и целевые лиды)
- Яндекс.Метрики (визиты, источники трафика)

Отчеты автоматически создаются в Google Sheets с детализацией по кампаниям, метрикам и каналам.

## 🎯 Структура отчета

### 4-уровневая иерархия:
1. **Итого** (все каналы)
2. **Яндекс Директ** (сумма 4 аккаунтов)
3. **Аккаунты**: e-20010227, e-17228851, dune-group, porg-3uieikjn
4. **Кампании** под каждым аккаунтом
5. **SEO** (отдельная строка)
6. **Рекомендации** (отдельная строка)

### Метрики:
- Показы
- Визиты (клики из Директа)
- CTR (%)
- CPC (руб)
- Лиды
- Конверсия в Лид (%)
- CPA (руб)
- Целевые Лиды
- Конверсия в Ц. Лид (%)
- CPL (руб)
- Расход (руб)

## 🔑 Ключевые правила для AI-агентов

### 1. Структура данных
- **Столбец "Визиты"** для строк Директа = **КЛИКИ** из рекламных кабинетов (НЕ визиты из Метрики!)
- Визиты из Метрики используются только для строки SEO
- Каждая кампания должна иметь свои реальные показы и клики из скриншотов

### 2. Атрибуция лидов
- **Лиды недели = ВСЕ записи CRM за период** (число строк LEAD CSV). Стадии НЕ исключаем — это требование пользователя (подтверждено 18.08.2026 на w13/w14/w15, 01.09.2026 на w17).
- Лиды с источником "Яндекс.Директ" → кабинет по UTM/активной кампании недели: `utm_campaign=713690254` → **porg-l2oigjze**, «МК ТК // Ремонт // remont.dune-group.ru» (117666311) → **e-20010227**, без UTM → активный платный кабинет недели (e-17228851 в w17)
- С w16 активен **5-й кабинет porg-l2oigjze** (товарная кампания remont, № 713690254) — не пропускать
- "Запросы по СЕО" → SEO; всё остальное (звонки, рекомендации, ТГ) → Другие/Рекомендации
- **Целевые лиды** = стадия "Целевой лид"
- **Рекомендации** определяются вручную пользователем

### 3. Формулы метрик
```
CTR = (Клики / Показы) × 100%, 2 знака
CPC = Расход / Клики, целые рубли
CPA = Расход / Лиды, целые рубли
CPL = Расход / Целевые Лиды, целые рубли
Конверсия в Лид = (Лиды / Клики) × 100%, 2 знака
Конверсия в Ц. Лид = (Целевые / Лиды) × 100%, 2 знака
При делении на 0 → прочерк "—" или "-"
```

## 📝 Процесс создания нового отчета

### Шаг 1: Сбор данных
Запросите у пользователя:
1. **Скриншоты Яндекс.Директ** с детализацией по кампаниям (обязательно!)
2. **CRM CSV** с лидами за период
3. **Данные Яндекс.Метрики** (визиты, источники трафика)

### Шаг 2: Извлечение данных
Из скриншотов для КАЖДОЙ кампании извлеките:
- Показы
- Клики
- Расход
- Конверсии

### Шаг 3: Анализ CRM
- Подсчитайте лиды и целевые лиды
- Определите атрибуцию по аккаунтам (по UTM или marquiz)
- Исключите нецелевые стадии

### Шаг 4: Создание скрипта
Используйте `report_2505.py` как шаблон:
```python
TAB_NAME = "DD.MM-DD.MM"
ROWS = [
    ["DD.MM.YYYY–DD.MM.YYYY"],
    [],
    [],
    ["Канал","Показы","Визиты",...],
    # Итого
    # Яндекс Директ
    # Аккаунты и кампании
    # SEO
    # Рекомендации
]
```

### Шаг 5: Проверка
Убедитесь, что данные совпадают со скриншотами перед запуском!

### Шаг 6: Запуск
```bash
python report_DDMM.py
```
